## Main commands

```bash
npx pnpm dev                # Run the Next.js app in development mode (hot-reload)
npx pnpm build              # Build the app for production
npx pnpm start              # Start the built app in production
npx pnpm lint               # Run linter (ESLint)
npx pnpm format             # Format all code via Prettier
npx pnpm format:check       # Check if the codebase is formatted
npx pnpm typecheck          # Type-check the entire codebase
npx pnpm prepare            # Initialize Husky hooks (after install)
```
