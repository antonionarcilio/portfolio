## 3. Painel de biografia expandida (padrão `MinimalistA11yPanel`)

- [x] 3.1 Criar o painel de bio expandida como componente próprio `AboutBioPanel` (`about-bio-panel.tsx`, mesmo padrão de arquivo por componente já usado por `a11y-panel.tsx`) — montado apenas quando `open` é `true`. Ajustado do plano: o painel é renderizado em `MinimalistRecruiter` (irmão de `MinimalistA11yPanel`/`.minimalist__content` dentro de `.minimalist__main`), não dentro de `AboutPage` — necessário porque `.minimalist__content-track` recebe um `transform` inline do Framer Motion (`animate={{ y: ... }}`), o que o torna o *containing block* de qualquer descendente `position: absolute`/`fixed` nele; um painel renderizado dentro de `AboutPage` (descendente de `.minimalist__content-track`) ficaria ancorado a essa faixa de 400% de altura, não à área de conteúdo visível.
- [x] 3.2 Seguir o padrão estrutural de `a11y-panel.tsx`: `motion.aside` com `position: absolute; inset: 0` relativo a `.minimalist__main` (já `position: relative`, e fora da cadeia de `transform` do content-track por estar num nível acima), fundo sólido (`var(--minimalist-background)`), transição `initial`/`animate`/`exit` de opacidade (sem `layout`/geometria FLIP), `onWheel={(event) => event.stopPropagation()}`.
- [x] 3.3 Renderizar `bio.description` completo via `MarkdownText` dentro do painel, com scroll interno (`overflow-y: auto` em `.minimalist__about-bio-panel__content`) e gradiente de fade no rodapé quando há overflow (`showGradient`, mesmo padrão de `card.tsx`'s `showExpandedGradient`/`ProjectsPage`'s `showProjectGradient`). - [x] 3.4 Renderizar o controle de recolher (`t('collapse')`) dentro do painel, chamando `onClose`; foco vai para o botão de recolher ao abrir (`useEffect` + `collapseRef`), e volta para o botão "Expandir" da página ao fechar (`aboutExpandTriggerRef` em `MinimalistRecruiter`); `aria-label={t('pages.about')}` no `motion.aside` como landmark.
- [x] 3.5 `hasExpandedContent`/paginação lateral/footer continuam bloqueando a navegação global (nenhuma mudança necessária ali). Ajuste adicional não previsto no plano original: `.minimalist__content` agora também fica `inert`/`aria-hidden` quando `isAboutExpanded` (antes só durante `a11yOpen`) — necessário porque o painel vive fora de `.minimalist__content` como um overlay irmão (como o menu de acessibilidade), então sem isso o botão "Expandir"/conteúdo compacto por baixo continuaria focável via teclado enquanto o painel está aberto. Isso não afeta Projetos: o card expandido de Projetos continua vivendo dentro de `.minimalist__content` e não é afetado por essa condição (que só reage a `isAboutExpanded`, não a `hasExpandedProject`).
